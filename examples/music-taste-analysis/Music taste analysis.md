# Music Taste Analysis

This example demonstrates how to analyze music taste and preferences using the Apple Music API integration in Ballerina.

## Prerequisites

1. **Apple Music Setup**
   > Refer the [Apple Music setup guide](https://central.ballerina.io/ballerinax/apple.music) here.

2. For this example, create a `Config.toml` file with your credentials:

```toml
# Add your Apple Music API credentials here
# Follow the Apple Music setup guide to obtain these values
```

## Run the example

Execute the following command to run the example. The script will print its progress to the console.

```shell
bal run
```
