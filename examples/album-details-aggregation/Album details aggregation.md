# Album Details Aggregation

This example demonstrates how to aggregate and display album details using the Apple Music API integration in Ballerina.

## Prerequisites

1. **Apple Music Setup**
   > Refer to the [Apple Music setup guide](https://central.ballerina.io/ballerinax/apple.music) to obtain the necessary credentials and configure your Apple Music developer account.

2. For this example, create a `Config.toml` file with your credentials:

```toml
# Add your Apple Music API credentials here
# Follow the Apple Music setup guide to obtain these values
```

## Run the Example

Execute the following command to run the example. The script will aggregate album details and print the results to the console.

```shell
bal run
```

The application will fetch and display album information from the Apple Music API, demonstrating how to work with music catalog data in Ballerina.
